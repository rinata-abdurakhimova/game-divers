# Input Actions Notes

Use these names because they are reserved in `INTEGRATION_CONTRACT.md`.

## Required Actions

- `move_left`
- `move_right`
- `move_up`
- `move_down`
- `action`
- `pause`
- `restart`

## Suggested Keyboard Defaults

- `move_left`: A, Left
- `move_right`: D, Right
- `move_up`: W, Up
- `move_down`: S, Down
- `action`: Space, Enter, E
- `pause`: Escape
- `restart`: R

## Suggested Controller Defaults

- movement: left stick or D-pad
- `action`: south face button
- `pause`: start/options
- `restart`: select/back or hold action after outcome

Do not rename these after integration without updating producers and consumers together.
